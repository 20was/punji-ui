'@punji/ui': minor

Charts parity with the web kit. `PerformanceChart` gains optional layers, all off by default so existing charts do not change: `reference` (a dashed, labelled target or alert line; a far one is pinned to the edge and said so), `drawdown` (the fall from each high as a band, with a table column and a spoken value), `contributions` (the money put in, dotted, on the same scale), `endLabels` (each series' last value at the right edge, spread apart with the new `spreadLabels`), `rebase={100}` (a compare mode that plots every series as an index from 100), `axis="quiet"` (three levels inside the plot, first and last dates only) and `onActiveChange` (the scrubbed date); `drawdownOf` is exported. New beta components, each built on `ChartA11yShell` or a real table: `MonthGrid` (`@punji/ui/month-grid`, year by month returns with Bikram Sambat or Gregorian month heads and a pickable month), `ReturnsHeatTable` (`@punji/ui/returns-heat-table`, subject by period, sortable heads, `heatCell`), `Histogram` (`@punji/ui/histogram`, bucket counts with a kept-range highlight) and `CorrelationMatrix` (`@punji/ui/correlation-matrix`). Every heat cell prints its signed figure, and the darkest shades are checked against the text colour in `check:contrast`. `squarify` now returns an empty layout for bounds with no area instead of throwing a `RangeError`, so a treemap measured at width 0 on a first render is safe.

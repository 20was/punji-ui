Table presets and lighter tables (beta): new `@punji/ui/table-presets` subpath with typed `ColumnDef[]` factories for holdings, stock quotes, ledger, bank statement, receivables aging and trial balance (`holdingsColumns`, `stockQuoteColumns`, `ledgerColumns`, `statementColumns`, `agingColumns`, `trialBalanceColumns`). Cells are formatted from exact bigint minor units, money columns total with a `sum` aggregate, and every head is replaceable through `labels`. `toFinancialColumns` (also in `@punji/ui/table-core`) turns a `ColumnDef[]` into the columns `FinancialTable` and `VirtualFinancialTable` take. Grouping, subtotals, totals and reconciliation moved out of the two tables into `@punji/ui/table-totals` (`tableTotals`, `TableTotalsEngine`): a table that never uses `groupBy`, `totals` or `expectedTotals` no longer ships them (about 0.7 kB gzip less each). Existing props keep working; without the new optional `totalsEngine` prop the tables load that code on first use, so the first draw is the plain rows. Pass `totalsEngine={tableTotals}` for the first paint and server output.

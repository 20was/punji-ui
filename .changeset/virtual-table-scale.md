Large tables without a dependency. `VirtualFinancialTable` (`@punji/ui/virtual-table`) takes FinancialTable's typed columns and draws only the rows in view, so a 10,000-row floorsheet renders in about 2 ms and applies 1,000 live row updates a second (docs/PERFORMANCE.md). It keeps `aria-rowcount`/`aria-rowindex`, a roving row focus (arrows, Page Up/Down, Home/End, Space to select) that survives scrolling, a sticky head, left and right pinned columns, pointer and keyboard column resizing reported through `onColumnResize`, and multi-column sort (Shift adds a column; priority shown and announced) with the pure `nextSortRules` and `compareByRules`. Live rows inserted above the view keep the reader in place; server rendering draws the first screenful. `TableExport` (`@punji/ui/table-export`) adds visible, all and selected CSV export buttons over `toCsv` with formula neutralisation always on, plus `rowsWithIds`. Styles in `css/virtual-table.css`. FinancialTable is unchanged.

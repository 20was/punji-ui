the existing financial-symbol combobox and company picker. No upstream

## Changes

Symbol suggestions are anchored to the actual input control. On narrow screens
the short suggestion list expands in document flow so it does not cover the next
price/quantity field. Pointer-down selection preserves input focus across mouse,
pen, and touch. Blur closes the list immediately; Escape cancels the open list;
active-descendant IDs clamp when the supplied symbol list changes. Hints/errors
are associated with the combobox, and a collapsed combobox no longer points to a
missing listbox ID.

The larger CompanySearch picker now exposes `aria-controls` only when its
lazy-mounted popup is present and the corresponding input is the active
combobox (including the full-screen phone sheet). This keeps the WAI-ARIA
relationship truthful in closed, typing, empty-result, loading and modal states.

The general field API and filtering behavior are unchanged. The existing search
limit stays in the shared pure utility. Existing licenses are reference-only;
no upstream source is distributed, so no new notice is required.

# Select source review — 2026-10-29

Reviewed actual source and tests before choosing a small, backward-compatible
improvement to the existing Select. No upstream implementation was copied and
no package was added.

The selected approach is progressive enhancement. It deliberately retains the
OS picker on touch and when feature support is absent. It does not promise the
same menu on every engine. A custom all-browser listbox would introduce new
focus, keyboard, positioning, form-proxy and assistive-technology responsibilities
or a dependency; those costs are not justified for this backward-compatible pass.

All listed licences are compatible references for this MIT project. No third-
party source is bundled, so no additional source-derived notice is required.
Existing THIRD_PARTY_NOTICES remains unchanged.

## Budgets

Measured Select JS is ~1.18 kB gzip including the existing media hook and a
browser-owned selected-content upgrade. Its allowance is 1.3 kB. Dependent
Fields/Calendar/DatePicker allowances become 2.65/8.4/11.5 kB; aggregate JS is
29.2 kB. Popover's 2 kB allowance covers the nested native-picker Escape guard.
Other primitive budgets, including root Button tree shaking, stay unchanged.
Select CSS has a dedicated 1.5 kB allowance and aggregate CSS 12.9 kB. These are
reviewed feature additions, not unrelated budget increases.

## Framework and integration decisions

Long selected labels need the platform's explicit selectedcontent display to
truncate before the chevron. The WPT keyboard fixture tests both default and
custom native display buttons. Server rendering this new markup into older HTML
parsers or React nesting validators is unsafe. Use the existing hydration-safe
media store, then create only the inert native display button in a layout effect.
The browser updates its content from the real selection; do not mirror state,
clone financial labels manually, or alter React-managed options. Cleanup removes
only the owned display button. Feature/touch/native opt-outs keep old markup.

The upgraded month Select exposed a nested Escape conflict in Popover. An open
native picker now receives Escape/Tab before its enclosing overlay; Escape then
closes the calendar only after the native menu is closed. Unit and real-browser
checks cover this integration.
